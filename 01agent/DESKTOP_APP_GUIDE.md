## 🤖 **Connect Your AI Agent**

To connect your Python AI agent to the desktop app:

```bash

set 01AGENT_API_URL=http://localhost:8001
set 01AGENT_THREAD_ID=desktop-session
set 01AGENT_USER_ACCESS_TOKEN=desktop-token
python main.py
```
